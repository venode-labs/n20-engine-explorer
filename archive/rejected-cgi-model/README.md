# Rejected CGI N20 model

This folder holds the previous production engine: a Three.js primitive assembly
(`N20Assembly.tsx` plus procedural materials, profiles and hoses).

It was removed from the live scene on 5 September 2026 because it failed visual
acceptance — it read as a Blender/CGI interpretation of an N20, not as a
photograph of a physical engine.

Do **not** load these files in the production viewer.

The live visual is a CC BY-SA photograph of a real N20 (BMW Welt display,
Hullie 2012) plus an F30 in-bay plate (HLW 2012), with an invisible hit layer
for interaction.
